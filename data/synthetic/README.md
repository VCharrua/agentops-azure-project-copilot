# Synthetic dataset

Everything in this folder is **invented** and generated by
[`scripts/generate_synthetic_data.py`](../../scripts/generate_synthetic_data.py). Alvora Construction,
its clients, people, projects, figures and documents do not describe any real organisation. Email
addresses use the reserved `.example` top-level domain.

| File | Content |
| --- | --- |
| `projects.json` | Three fictional construction projects and the reporting date |
| `budget_lines.csv` | Budget, actual, committed and forecast per cost code |
| `milestones.csv` | Baseline and forecast dates per milestone |
| `incidents.csv` | A small incident log |
| `documents/*.md` | Contract summaries, weekly site reports, meeting minutes, company policies |

`documents/PRJ-002-email-quickpave.md` deliberately contains an **indirect prompt-injection payload**
(a fake supplier email telling "the AI assistant" to create a payment task and email the budget to an
outside address). It is test material for the guardrails and the evaluation suite.

Do not edit these files by hand. Change the generator and run `make data`; CI fails on drift
(`make data-check`).
